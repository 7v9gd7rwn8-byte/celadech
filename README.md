# Celadech - App Cuisine 🍳

Une application web complète pour explorer, partager et gérer des recettes.

## 🍷 Fonctionnalités

- 📖 Catalogue de recettes avec recherche et filtres
- 👤 Profils utilisateurs et favoris personnalisés
- 📝 Création et édition de recettes
- 📋 Planification de menus hebdomadaires
- 🛒 Gestion de liste d'achats intelligente
- ⭐ Système de notations et commentaires
- 📊 Analyse nutritionnelle
- 🌙 Mode sombre/clair
- 📱 Design responsive

## 🏗️ Architecture

```
celadech/
├── frontend/          # Application React/Next.js
├── backend/           # API Node.js/Express
├── mobile/            # App React Native (optionnel)
└── docs/              # Documentation
```

## 🚀 Démarrage rapide

### Prérequis
- Node.js 18+
- npm ou yarn
- PostgreSQL

### Installation

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend (nouveau terminal)
cd backend
npm install
npm run dev
```
